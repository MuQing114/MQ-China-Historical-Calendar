# MQ中国历史历日检索 · 夏至今 · 离线版

数据版本：2026-11-09，查询截至该日。网页、数据和查询逻辑均在本地，不需要服务器、账号或网络。此次未上传或修改在线站点。

程序版本2.1.0新增生日排盘，可在页首点击“生日排盘”，输入生日查看四柱八字、整柱纳音、日主及月令格局参考。

## 打开方法

双击 `dist/MQ中国历史历日检索_夏至今_离线版.html`，用 Edge、Chrome 或 Firefox 打开。这个 HTML 已内置所有必要样式、脚本、历表和纪年数据，单独复制它也可以使用。`dist/index.html` 是便于修改的多文件版，使用时须与旁边的 JS、CSS 文件放在一起。

## 可以怎样查

| 方向 | 输入示例 | 输出 |
| --- | --- | --- |
| 干支查 | 明代范围输入 `戊申年` | 1368、1428、1488、1548、1608年 |
| 完整干支 | `戊申年甲寅月甲子日丙寅时` | 候选公历日期、农历/史历日期和约两小时的时辰区间 |
| 年号查 | `洪武十八年二月廿七日` | 公历1385-04-15；儒略历1385-04-07；己未日 |
| 公历查 | `225-06-01` | 基准史历及魏、蜀、吴的年号和各自历日；其中吴历为闰四月 |
| 农历查 | 1385年、二月、廿七 | 公历、儒略历、干支及并存政权纪年 |
| 公元前 | `前722-02-01` | 数学日期对照及可用的古历复原；不用公元0年 |
| 只有年度资料 | `大理天开三年` | 1207年度候选；不伪造月日换算 |
| 近现代 | 公历日期，或 `民国一百一十五年十一月初九日` | 公元和民国纪年；后者的月日按公历解释，并注明它不是帝王年号 |

“全部/明/宋辽金夏”等按钮控制干支和农历检索的候选范围。切换到其他年代而查不到时，先检查范围。公历反查不受候选范围限制，支持前2070年至2026-11-09；年份范围可选2026年，但其中晚于本版日期的月日不会列成历史结果。

结果下方可在“本日、本月、本年”之间切换：

- **本日历表对照**：列出来源历表在该日对应的各政权年号、君主纪年和当地月日。当地没有月日资料时，不借用基准史历冒充。
- **本月/本年所有纪年**：包括范围内先后改元、并存政权和不同纪年年次。列在一起不表示同时在用。
- **年度候选**：资料只到年或月级，或者仅知相关君主在位的可能范围。不能证明所选那一天实际在用。

可搜索全部纪年索引，查看“来源与原注”；可导出查询结果或索引 CSV，或复制某日信息。简繁字可检索，同名年号保留多个政权，不默认选一个。

## 生日八字、整柱纳音与命格参考

页首点击“生日排盘”，选择公历或农历生日，填写出生日期和时间后点击“生成八字与纳音”。也可把上方正在查看的日期直接送入排盘。

- **公历生日**填 `1986-05-29`；历史文献用儒略历时可切换。农历生日填具体年份或完整年号年、月份和日数，闰月写“闰二”等；有多个日期候选须先选择。
- **出生时间**可填具体时分、只选时辰，或明确时辰不详。未填时间不会补成00:00；时柱留空。子时横跨早子和晚子，必要时分列候选。
- **四柱与纳音**按所选规则显示年、月、日、时柱，以及四柱各自的整柱纳音、本气五行、天干十神和地支藏干。纳音逐项据《卜筮全书·六十甲子歌》，采用原书的“路傍土、井泉水、砂中金、覆灯火”等名称。
- **年、月柱分界**默认按现代定气，年柱在立春换年，月柱在十二节换月；不把农历初一当作八字月柱分界。可改为历书交节日口径。历史生日属于按所选规则回排，未必等于当时实际命书排法。
- **换日**默认子初：日柱和时干均23:00换日；可选两者均00:00，或日柱00:00、时干23:00的早晚子口径。生日模块的设置独立于普通历日查询。
- **时区**默认输入钟面为UTC+8，可按15分钟调整固定UTC时差。没有自动夏令时或地方真太阳时校正；夏令时出生须填记录当时的实际时差。所选农历仍依中国基准/当地史历，不据海外时差重编阴阳历。
- **命格分项**显示“年命纳音（立春年柱口径）”“日主”“月令格局参考”。农历岁首口径年命另列；立春与春节之间可能不同。
- **格局规则**采用月令本气配日干十神的简法，另辨禄位、阳干帝旺月、杂气月，并展示月令藏干在年、月、时干中的透出线索。页面明确给出依据，不自动断定成格、从格、喜用神或富贵吉凶。这些是传统术数文化分类，不是人生结果预测。
- **五行计数**仅为四干及四支本气的表层计数，完整四柱共8字；藏干涉及的五行另列。表层未见某行不等于命理“缺某行”。

交节日时间不详时可能存在多盘；页面列全候选，复制排盘时也保留全部候选及口径说明。夏商及无相应节气表的时期不造出年/月柱；仅年度资料不能冒充确定农历生日。出生输入不写入文件、浏览器存储或网络。

原文、规则和独立验证数据见 `sources/birth-rules/`。原2.0离线文件的备份位于 `backups/中国历史历日检索_新增生日排盘前_20261109.html`。

## 覆盖和必要界限

本版包含 **34,004个基准史历月份/片段、1,962条纪年记录**；包含重复异说、君主纪年、存疑及判伪索引，不等于1,962个已核实年号。411个来源标签也不等于411个独立政权。

| 时期 | 支持程度 |
| --- | --- |
| 夏、商及早期西周 | 以约前2070年为夏代入口，提供年代定位。没有可据以恢复全段的逐日农历，故明确留空。公历、儒略历、日干支仅为数学回推。 |
| 前841年起的君主纪年 | 使用来源记载及其异说；早期资料通常只有年级精度。 |
| 前722年至前105年前后 | 鲁历、颛顼历等古历复原，属于选定模型，不能理解为所有地区实用同一历法。前722年的儒略年界折成公历为前723-12-24，故开头带有前一年底片段。秦汉保留“后九月”等古月名。 |
| 前104年太初改历以后 | 主历主要依张培瑜《三千五百年历日天象》及Y. T. Liu校正资料；保留王莽、曹魏、武周、唐肃宗等月名及岁首变动。 |
| 三国、南北朝、五代、宋辽金夏、明清交替等 | 并列所有已收录来源中命中的政权纪年。CeJS提供当地月表时可独立换算；南诏、大理等补充资料只到年度，另列候选。 |
| 近现代至2026年 | 现代农历、公历、干支，以及公元和民国纪年；无帝王年号的制度明确标注。 |

小政权、地方割据及年号异说没有一份公认且完整无误的总表。本工具尽量保留所收集资料，并明确精度、出处和疑伪，不承诺穷尽尚未确证的所有政治实体。收录年号沿用期不一定等于其最初政权实际存续期，日级历表也可能含年初追记、死后沿用或复称；不能直接当成某天的政治版图。

默认现代日期使用**全段向前推算的格里高利历**，与许多旧资料在1582年前使用的儒略历可能不同，故同时给出两者。用户界面没有公元0年：前1年接公元1年；内部计算用天文年号。

史历月、历书节月、现代定气节月分开处理。普通阴阳历闰月通常沿用前月干支；春秋复原缺少可靠的月建时留空。历书节月以来源的交节日换月；1645年前为平气、以后为定气；1734年后缺旧历书表时以现代交节日期参照。现代定气推算按UT1+8/UTC+8表述到分钟，不冒充古代实测。

日、时干支可选择00:00或23:00换日；农历月日仍按民用日期标注。时辰只表示约两小时的钟面区间，未校正地点经度、真太阳时，也不会由一个时辰捏造精确分钟。

## 重建与检查

需要Node.js及Python 3，日常使用网页不需要安装它们。

```text
node tools/build-calendar-data.cjs
node tools/build-era-data.cjs
python -B -X utf8 tools/extract-year-supplement.py
node tools/test-calendar.cjs
node tools/test-birth.cjs
python -B -X utf8 tools/package-local.py
```

`sources/calendar-compilation-report.json` 记录主历连续性和覆盖，`sources/era-compilation-report.json` 记录来源缺项及编译情况。测试包括整个支持区间的公历/儒略历往返、全部主历片段连续性、公元前纪年、特殊改历、明代旧例、三国并历、近现代纪年、晚子时换日和疑伪过滤。

生日专项测试另覆盖11个独立期望四柱样例、六十甲子纳音、2024年立春前后、三种晚子口径、时辰未知候选、农历闰月、同名年号、固定UTC时差及不足资料拒绝排盘等。
